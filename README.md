# TRIVIUM120° — نظام الأتمتة والتحكم الرقمي

## للعمال والمشغلين:
نظام ذكي متكامل يجعل من عملية تصميم الصواني الدائرية ونقشها عملاً بسيطاً ودقيقاً.
- **واجهة مستخدم بديهية:** صُممت وفق معايير Samsung One UI، لتسهيل التعامل مع إعدادات الآلة، تقليل الأخطاء البشرية، وتسريع دورة العمل.
- **تصميم أوتوماتيكي:** بمجرد إدخال قطر الصينية، يقوم النظام بحساب المصفوفة الهندسية وتوزيع الثقوب (بتناظر 120 درجة) بدقة مليمترية.
- **محاكاة لحظية:** تتبع حركة الرؤوس الثلاثة ومسار الحفر مباشرة على شاشة هاتفك قبل بدء العمل، مما يضمن خلوص القطع وسلامة المنتج.
- **تبادل الوصفات:** استبدل الكابلات المعقدة بمسح رموز QR؛ انقل وصفات الإنتاج من وإلى الـ HMI في ثوانٍ.

## لأصحاب الأعمال والمصانع:
TRIVIUM120° هو أداة لزيادة الإنتاجية وتقليل الهدر الرقمي والمادي.
- **تحول رقمي فوري:** يرفع كفاءة آلات النقش التقليدية ويحولها إلى وحدات إنتاج ذكية قابلة للبرمجة.
- **موثوقية هندسية:** محرك رياضي صارم يضمن عدم تداخل الثقوب، ويحمي الرؤوس والأسنان من التلف، ويضمن تناسق جودة المنتج النهائي.
- **مرونة الإنتاج:** إعداد وصفات جديدة وتعديل الإعدادات الحالية يتم في لحظات، مما يقلل وقت التوقف بين طلبية وأخرى.
- **دعم اللغة والتقنية:** النظام يدعم العربية والفرنسية، ويعمل بالكامل كـ PWA (تطبيق ويب متقدم) دون الحاجة لاتصال دائم بالإنترنت داخل الورشة.
